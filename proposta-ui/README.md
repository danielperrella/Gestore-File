# Proposta front-end

Aprire `index.html` nel browser, anche senza connessione. Il prototipo è autonomo: nessuna dipendenza, font remoto o accesso ai file reali. Ricaricare la pagina ripristina tutti i dati demo.

Direzione: superfici bianco/celeste (#f4f7fc), testo ardesia (#182536), cobalto (#2459e0), cartelle ambra (#edbd55), stato verde (#218778), separatori #e5eaf2. Segoe UI/system per conservare leggibilità e funzionamento offline. Layout mobile con navigazione inferiore e azioni contestuali sopra di essa; su desktop posizioni in una colonna laterale. Il colore più forte identifica la memoria principale, non schede decorative.

Flussi navigabili: memoria interna e USB, breadcrumb, cartelle, preferiti e recenti, elenco/griglia, ordinamento, selezione multipla, copia/sposta con destinazione e gestione duplicati (conserva entrambi/salta), creazione cartella, rinomina anche con prefisso, cestino/ripristino/eliminazione, ZIP/estrazione dimostrativi, dettagli, file nascosti e analisi manuale illustrativa.

È una proposta del flusso principale, non una riscrittura dell'app Android: trasferimenti e ZIP modificano soltanto gli oggetti demo. Non sono implementati apertura/condivisione Android, permessi SAF, coda con avanzamento, sostituzione file, recupero operazioni interrotte, tutte le varianti di rinomina multipla o tema scuro. Dimensioni delle memorie e analisi sono illustrative. Nessuna ricerca, cloud o anteprima multimediale, coerentemente con il README del prodotto.
