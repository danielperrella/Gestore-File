Gestore File

Privacy

Aggiornata il 19 ottobre 2026. La versione pubblica 0.3.0 gestisce file locali e usa Internet per gli aggiornamenti. Le sezioni Google Drive descrivono la candidata 0.4.0 e si applicano soltanto quando colleghi volontariamente un account in una build abilitata.

File locali

L’app gestisce i file sul telefono e sulle memorie autorizzate. Non li carica online automaticamente. Non utilizza pubblicità, statistiche di utilizzo o un server applicativo. Gli aggiornamenti vengono richiesti a GitHub Pages, che riceve i normali dati di connessione.

Google Drive, facoltativo

Se colleghi un account, l’app richiede il permesso di visualizzare e gestire i file di Google Drive per consentire navigazione, copie, caricamenti, rinomina, spostamenti, esportazione e cestino. Le richieste e i file viaggiano direttamente tra il telefono e Google tramite HTTPS, secondo le tue azioni. Non vengono inviati a un server dello sviluppatore.

Il dispositivo conserva privatamente indirizzo email e identificatore dell’account, riferimenti di preferiti e recenti, e un registro delle operazioni interrotte. I token di accesso sono mantenuti in memoria: l’app non salva password o refresh token. Google Play Services gestisce l’autorizzazione Google sul dispositivo.

Cache e condivisione

Caricamenti, aperture, condivisioni ed esportazioni possono richiedere file temporanei nella cache privata dell’app. I file scaricati per apertura o condivisione vengono esposti in sola lettura alle app scelte dall’utente tramite autorizzazioni Android con scadenza di 24 ore. La cache scaduta viene rimossa al successivo avvio; Android può liberarla prima. Non è una modalità offline di sincronizzazione.

Scollegamento e cancellazione

Da Posizioni → Account Google Drive puoi scollegare ciascun account: l’app richiede a Google la revoca dell’accesso e rimuove cache e riferimenti locali di quell’account. Non elimina i file online. Puoi revocare l’accesso anche dalle impostazioni di sicurezza del tuo account Google. Cancellare i dati dell’app rimuove le impostazioni locali; non costituisce una revoca su Google.

Il cestino di Drive e quello locale sono distinti. L’app non svuota automaticamente i cestini e non elimina definitivamente i contenuti di Drive.

Uso dei dati Google

L’uso e il trasferimento delle informazioni ricevute dalle API Google rispettano la Google API Services User Data Policy, inclusi i requisiti Limited Use. I dati non vengono venduti, utilizzati per pubblicità o per addestrare modelli di intelligenza artificiale.

Assistenza

Il progetto è mantenuto da Daniel Perrella. Per richieste sulla privacy usa le segnalazioni del progetto, senza includere credenziali o contenuti privati. Account e file dell’utente non sono disponibili allo sviluppatore tramite l’app.
